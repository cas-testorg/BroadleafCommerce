# Demo Goal

Demonstrate how MCP can provide application-specific context to AI development tools.

## Scenario

A development team inherited a large Broadleaf Commerce application.

They want to modernize the platform using AI-assisted development.

## Challenge

AI tools understand source code.

They do not automatically understand:

- Architecture
- Modernization priorities
- Dependency risks
- Organizational guidance

## Solution

Provide structured application context through MCP.

The AI assistant can:

- Retrieve architecture information
- Retrieve modernization guidance
- Retrieve dependency information
- Retrieve risk assessments

before making recommendations.

## Outcome

AI recommendations become more informed and lower risk.
